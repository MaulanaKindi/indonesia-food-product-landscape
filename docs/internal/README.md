# Internal working notes

These files are working notes, not documentation. They record how the project was built and checked, and they are kept in the repository for traceability rather than for readers.

| File | What it holds |
|---|---|
| `STATE.md` | The internal audit state: scores, backlog items, gate status, and verification notes. |
| `AUDIT_REPORT.md` | The internal audit report: scoring rubric, findings, and release record. |
| `99_project_log.md` | A dated log of decisions, reasons, and verification steps. |

Nothing here overrides the numbered documents in `docs/`. If an internal note and a numbered document disagree, the numbered document is the published record and the note describes the working state at the time it was written.

Published claims, numbers, and limitations live in `docs/01` through `docs/11` and in the root `README.md`.
