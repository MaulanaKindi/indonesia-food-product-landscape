# 03 Analysis Workflow and Quality Gates

## Purpose

This workflow turns the business brief into ordered, reviewable stages. Each stage lists its expected evidence and a gate that must be met before dependent work is treated as final. Work may proceed provisionally when noted, but unresolved decisions must remain visible and must not be presented as validated conclusions.

## Working Rules

- Use the traceability flow **data and approved mappings → scripts/SQL → outputs/evidence → documentation**. Each result should be reproducible from its recorded inputs and transformation.
- Apply a quality-control gate against garbage-in/garbage-out: validate source identity and scope, mapping status and coverage, units/denominators, transformation logic, and output reconciliations before interpretation. Passing technical checks does not establish mapping truth, representativeness, or commercial validity.
- Treat harmonization as a controlled feedback loop, not a mandatory full-review phase: a measured result may trigger a specific, impact-based mapping review; an approved mapping change becomes an input to the affected analysis, which must then be rerun and revalidated.
- Maintain the information architecture and ChatGPT handoff when a material decision, workflow, file location, output, or project status changes. Keep project documentation and evidence as the source of truth; the handoff is a synchronized summary.
- Keep the source snapshot unchanged; all transformations must be reproducible.
- Preserve source values and record-level evidence. Put cleaning, mappings, and exclusions in explicit, reviewable steps.
- Treat the source row as the default unit until a product-identity rule is validated.
- Do not infer market size, sales share, or commercial dominance from Open Food Facts record counts.
- Every material result must link its source, transformation, output, metric definition, and limitation.
- Record substantive decisions in the project log and update the business brief or data profile when the agreed measurement rules change.
- A gate is passed only when its stated checks and evidence are available; a script completing successfully alone does not pass an analytical gate.
- Full harmonization is not itself a GIGO guarantee. Do not force uncertain values into categories for apparent completeness; preserve unresolved status and disclose coverage when evidence is insufficient.
